## What works

- **Two-layer token indirection turns one stylesheet into eight palettes.** A raw palette layer names *pigments* (`--brand-yellow`, `--purple`, `--screen-black`); a semantic layer names *roles* (`--page-bg`, `--text`, `--button-bg`, `--button-text`, `--link`, `--card-border`). Every component references only roles. Each full-bleed band then re-points the role layer and nothing else — `[data-color="yellow"] { --page-bg: var(--brand-yellow); --text: var(--screen-black); --button-bg: var(--purple); --button-text: var(--white) }` — so a button, a card, and a form get correct contrast on eight different grounds with zero per-section component CSS. The dark-mode block is the *same* mechanism pointed at different pigments, which is why dark mode costs ~15 lines here instead of a parallel stylesheet. Transfers to any product with themed surfaces: the rule is *components never name a pigment*, and a theme is a remap of roles, not a set of overrides.
- **The fixed chrome adopts the palette of the section it is over, instead of defending itself with a scrim.** The navbar is `position:fixed` with a transparent background; an IntersectionObserver copies the current section's `data-color` up to `<html>`, and `#navbar.scrolled[data-color="…"]` inherits the same role remap — background, ink, wordmark, hairline rule, and the CTA pill all re-tint on a 250ms `background-color` transition. Frames confirm it: over yellow the nav is yellow with warm-black ink and a purple pill; over charcoal it is charcoal with white ink and the same purple pill. This is the cheapest real fix for the perennial "transparent header over arbitrary content" contrast bug — no `backdrop-filter`, no blur cost, no scrim that muddies both sides. Transfers to any long page whose header floats over content of unpredictable brightness.
- **Scale the whole page as one drawing: rem for every dimension, `vw` on the root, capped.** `html { font-size: 2.4px }` → `0.909vw` from 240px → hard-stopped at `10px` above 1100px. Because *everything* is rem — type, the 20rem cloud blobs, the 35rem game cards, the 107rem catalog container — the entire composition scales proportionally between phone and laptop, and breakpoints are only ever asked to reflow the grid, never to resize type. One knob replaces a `clamp()` per property. The cost is real and worth naming: a `vw` root overrides the user's browser font-size preference, so this trades an a11y affordance for proportional fidelity — acceptable for an art-directed brand page, wrong for a docs site or an app shell.
- **Let the product's physical constraints art-direct the page.** The ink is `#312f28` — the warm near-black of the device's own reflective LCD, not `#000`. The 24 game covers are 1-bit dithered, forced through `image-rendering: pixelated`, and dropped into a uniform 3-up grid of identically framed 1px-bordered cards. Twenty-four illustrations by twenty-four different artists read as one coherent system because the *medium* is enforced, not the style. Transfers to any catalog of heterogeneous third-party art — app icons, plugin logos, user uploads, integration marks: impose one rendering constraint (monochrome, dither, fixed frame, single stroke weight) rather than trying to police contributors' taste.
- **The saturated color band *is* the section divider.** No rules, no gradients, no diagonal cuts, no drop shadows between chapters: gray → yellow → black → white → yellow → aqua → purple → charcoal → purple, each band abrupt and each re-theming its own type and CTA. Chapter rhythm comes from band length and hue distance, which is what keeps a ~16,000px page navigable and lets you skim by color memory ("the aqua one is education"). Transfers to any long marketing page that has accumulated a decorative-divider habit — delete the dividers, promote the palette to structure.
- **Spectacle sits on top of a working page, never underneath it.** The hero's draggable WebGL device (`cursor: grab`, Three.js, `<canvas>`) degrades to a looping `<video>`, which degrades to a static PNG background, and `body.nojs` unpins the navbar entirely and reveals a red no-JS banner. The 3D device is the *top* rung of a ladder whose bottom rung still sells the product. Transfers to every canvas/3D hero: build the PNG first and treat the shader as an enhancement you are willing to lose.
- **Tactility is argued through the button, not just described in the copy.** The order CTA is a purple pill with a two-stop gradient plus a four-part inset shadow stack (light from above, dark from below, an interior glow, and a cast shadow). On `:active` the gradient darkens, the shadows invert inward, *and the padding shrinks by ~0.1em* — the pill physically depresses and the label sinks with it. For a product whose entire pitch is a crank you turn with your hand, the primary control being the one obviously pressable object on the page is argument, not decoration. Transfers wherever the product's claim is tactile: make the CTA the proof.

## Design-system read

- **Type:** One family, Roobert (geometric grotesque, warm and slightly cartoonish at large sizes), at three weights: 400 body, 700 emphasis, **800 for every heading**. Root is 10px above 1100px, so the scale in rem reads 1.1 / 1.85 / 2.14 / 2.4 / **2.85 (body)** / 3.42 / 5.13 / 6.84. Body is deliberately large (28.5px) and headings are only ~2.4× it (`h2 { font-size: 2.4em; line-height: 1 }` = 68.4px) — this is the *opposite* of the display-driven agency scale: hierarchy comes from **weight (400→800) plus the color band**, not from a 6× scale jump. Leading: 1.0 on headings, 1.3 on body. Only one tracking value in the whole page (≈ −0.006em on the wordmark) — the face is left alone. The `playdate` wordmark itself is not type at all: an SVG background-image on an `<h1>` whose text is zeroed out (`font-size:0; color:transparent`) so it stays a real heading for screen readers and SEO.
- **Color:** Nine pigments, ruthlessly assigned. Ground rotates per band; ink is always `--screen-black #312f28` on light bands and `#ffffff` on dark ones. **Purple `#6c00ff` is the only pigment that never changes role** — it is `--link`, `--interactive`, and `--button-bg` on every ground, which is what makes "the purple thing is the thing you press" learnable in one scroll. Brand yellow `#ffc833` is the accent on dark bands (spec icons, form labels, the "buy" CTA on black) and the *ground* on light ones — the same pigment inverted, not two yellows. Greys are warm-derived (`#312f28`, `#57554e`, `#7e7b75`, `#b1afa8`), not neutral, so nothing feels like default browser chrome. Every pigment ships a `@supports (color: color(display-p3 …))` variant, so the yellow and the purple gain real chroma on wide-gamut displays and fall back cleanly elsewhere.
- **Spacing rhythm:** Base unit is `1rem` = 10px at desktop root. Sections breathe on a heading margin of `6rem 0 3rem` (60/30px) — big top gap, half-size bottom gap, so a heading binds to the copy under it. Bands add `2rem` of internal padding and take their real height from content. Content sits in an `80rem` (800px) column; the catalog and spec grids widen to `107rem`/`110rem`. Density is low in prose, high in the two grids — the page alternates between them.
- **Layout system:** A center-stacked measure inside full-bleed bands. `display:grid` 17× / `flex` 20×; grid columns are 1 / 2 / 3 / 4 with no 12-column base anywhere. The game catalog is `grid-template-columns: 1fr 1fr 1fr; gap: 1rem` collapsing to `1fr` under 670px. The spec block is a `1fr 1fr` grid of `2fr 3fr` label/value sub-grids with per-item `order` and offsets that interleave two ragged columns; it collapses to a single column at 240px and just shrinks (`font-size: 0.75em`) at 670px. Breakpoints: **240 / 620 / 670 / 1100px** — mobile-first, and the 1100px one exists only to stop the `vw` root from scaling.
- **Layering / page architecture:** Essentially **a single flat scroll with one pinned layer**. `architecture.layers_summary`: 3 fixed, 0 sticky, `has_static_backdrop: false`, `has_blend_overlay: false`; `blend_glass` reports no `mix-blend-mode` and no `backdrop-filter` anywhere. The only real layer is the navbar (`z:101010`, 7% viewport height, transparent background) plus an inert `opacity:0` lightbox at `z:101020`. The high `transparent_height_pct: 48` is a false positive: `<section>`s are transparent because their *parent* `div.colorsection` paints the band — the color is one DOM level up, not on a fixed backdrop. Depth here is not z-axis at all; it is **hue distance between adjacent bands**. Worth stating plainly, because the reflex on a page this expressive is to add a fixed scene and blend it — Playdate proves you can get chapter-scale drama out of nothing but flat opaque rectangles and a re-tinting header.
- **Motion / easing intent:** `ease-in-out` and bare `ease` only; no custom cubic-bezier in the whole site. Two duration families: **UI, 150 / 200 / 250 / 300ms** (nav recolor 250ms, card skew 150ms, card flip 300ms), and **ambient, 3.5–5s** (the thought-cloud blobs). Nothing in between, and nothing entrance-related: `entranceReveals: 0`, `staggeredEntrance: false`. The page does not fade-rise into view; it is simply *there*, and only two things move — chrome that must react to you, and one decorative cloud that breathes. That restraint is the motion system. Choreography below.
- **Density:** Prose is sparse and set large; the catalog (24 cards) and spec table (10 groups × 2–5 rows) are dense. Legibility in the catalog survives because every card is the same frame at the same size in the same two inks — variation is confined to the artwork. The spec table survives because labels are muted grey, values are white, and the icon column is the only chroma.
- **Hierarchy:** Dominant ordering device is **color band**, then **weight**. Scale is the *weakest* of the three, which is unusual and is why the page reads friendly rather than shouty.
- **Restraint:** No entrance animations. No parallax. No blend modes, no glass, no backdrop-filter. No section dividers, no gradients except inside the one CTA and one loading fallback. No second typeface. No hover effects on anything but the cards and the CTA (`hoverEffects: 0` in the resting probe). One accent hue for interactivity, held constant across eight grounds.

## Interaction & motion

Motion here is **minimal and mostly hand-rolled CSS**, not a library scroll-rig. Evidence: `keyframes` (read from the real stylesheet, not the blocked-sheet probe count of 0) amounts to a *single* named animation, `blobble`; `cssAnimationRules` is effectively that one rule set; `entranceReveals: 0`; `hoverEffects: 0`; `mix_blend_mode: []`. Three.js is present but confined to two `<canvas>` product renders (`rafCalls: 953`, `canvas: 2`, `draggable: 2` — the device is orbit-draggable). Two IntersectionObservers over 28 targets drive the section→chrome palette handoff. `prefers-reduced-motion` is **respected in three places** (navbar transition, card skew/flip, catalog marquee) and the site even ships a `body.reduce-motion` class for its own user-level toggle — genuinely above the expressive-corpus average — but the ambient `blobble` loop is *not* gated, which is the one real miss.

- **Section→chrome palette handoff** — *Trigger:* in-view (2 IntersectionObservers, 28 observed targets). *Mechanism:* the observed band's `data-color` is mirrored onto `<html>`; `#navbar.scrolled[data-color]` re-points the same semantic role variables (`--page-bg`, `--text`, `--button-bg`), so the fixed header's background, ink, wordmark fill and hairline border all cross-fade on a 250ms `background-color` transition. *Reads as:* the header is *part of* the section rather than floating above it; the page feels like chapters rather than a scroll. *Transfers to:* any fixed nav over multi-toned content, any theme-per-section editorial page, any anchor-linked long-form doc. *Safety:* **production-safe** — one class + one attribute, no per-frame JS, no compositing cost, and it is explicitly reduced-motion-gated (the transition is dropped, the color still swaps). → `patterns/section-palette-handoff.md`
- **Idle blob-cluster wobble** — *Trigger:* load (infinite). *Mechanism:* ten absolutely-positioned `border-radius: 50%` divs share one `@keyframes blobble` that walks a *non-uniform* `scale(1.05, .97) → scale(.99, 1.03)`; each blob gets a different `animation-duration` (3.5s / 4.5s / 5s) and delay, `direction: alternate`, `ease-in-out`. The offsets never re-synchronise, so a rigid loop reads as organic drift. *Reads as:* a thought-cloud actually thinking — the page's one moment of whimsy, spent on the one section that is a quote. *Transfers to:* ambient hero atmospherics, loading states, mascot/illustration idles, anywhere you want "alive" without a physics engine. *Safety:* **production-safe with the gate, spectacle-only without it** — transform-only (compositor), zero layout, but it is an *infinite* animation, which is exactly the category `prefers-reduced-motion` exists for. Playdate does not gate it; the recipe below does. → `patterns/blob-cluster-idle-wobble.md`
- **3D card flip on a 1-bit grid** — *Trigger:* hover (skew) / click (flip). *Mechanism:* each catalog card is a `preserve-3d` container under `perspective(80rem)`; hover applies a small skew (150ms), activation rotates the container `rotateY(180deg)` (300ms) to reveal a `<dl>` of game metadata on the back face, both faces `backface-visibility: hidden`. The whole block sits inside `@media (prefers-reduced-motion: no-preference)`, so on `reduce` the transitions never attach. *Reads as:* a physical card in a box — the flip *is* the "what's on the other side" affordance. *Transfers to:* any grid where the reverse side carries specs (product tiles, trading-card UIs, team bios). *Safety:* **production-safe**, and note the correct construction: opt *in* to motion with `no-preference` rather than opt out with `reduce`.
- **Pressable CTA (skeuomorphic depress)** — *Trigger:* hover/active. *Mechanism:* a gradient pill with four inset shadows; `:active` swaps to a darker gradient, inverts the inset stack (dark above, light below), and reduces padding, so the label physically sinks. *Reads as:* a real button on a real device. *Transfers to:* primary CTAs on tactile/hardware products, game UI, anything wanting a pre-flat-design affordance without going full skeuomorph elsewhere. *Safety:* **production-safe** — `box-shadow`/`padding` on `:active` only, so the paint cost is a single pointer event; not on any scroll or hover hot path.
- **Draggable WebGL product render** — *Trigger:* drag (`cursor: grab`, `draggable: 2`, Three.js, 953 rAF calls in one scroll pass). *Mechanism:* two `<canvas>` elements render the device and an in-game demo; the user can orbit them. Each carries a `<video>` sibling and a static-PNG background fallback, swapped by a `body.loaded` class. *Reads as:* "hold the thing before you buy the thing." *Transfers to:* hardware/product landing pages where rotation answers a real question (what's on the back?). *Safety:* **spectacle-only** — a rAF loop plus a WebGL context is the single largest cost on the page (main-thread + GPU + battery on mobile), and it is not paused off-screen or under `reduce`. Ship it only behind the fallback ladder, pause it with an IntersectionObserver, and honor `prefers-reduced-motion`.

## Components

- **Buttons:** `div.button` — `border-radius: 1em` (pill), `padding: .25em .7em .35em` (note the asymmetric bottom padding, optical centering for the 800-weight cap-height), background `var(--button-bg)`, label `var(--button-text)` at weight 700, `text-decoration: none`. Variants are palette swaps (`.black`, `.yellow`, `.screenBlack`) and one size (`.big { font-size: 1.25em }`). The order CTA is the single elaborated instance (gradient + inset stack + `:active` depress, `border-radius: 3em`).
- **Cards:** `.card` — `var(--card-bg)`, `radius .5em`, and `.card.stroked { border: .1em solid var(--card-border) }`. Note `--card-border: var(--text)` — the border is *the ink itself*, not a grey. That is why cards read as drawn objects on every band instead of dissolving. Game cards go further: `1px solid var(--screen-black)`, square, no shadow, `image-rendering: pixelated`.
- **Nav:** 24 visible links, no hamburger at any width (`likely_hamburger: false`) — the mobile nav keeps every link, in a panel. Focus produces a `1px rgb(16,16,16)` outline on each anchor (the UA ring, not a designed `:focus-visible` token — the probe reports no authored focus-visible rule, so treat this as "keyboard-usable" rather than "keyboard-designed").
- **Inputs:** newsletter form on the charcoal band — `--input-bg: var(--page-bg)`, `--input-text: var(--text)`, white 1px border, yellow submit. The captured focus state on `<input>` is a transparent border, i.e. **the focus ring is removed on the one control where it matters most.** Do not copy this.
- **Shadow scale:** effectively none. Three flat shadows exist (`0 1px 3px rgba(0,0,0,.3|.5)`), all on small chrome. Elevation is not part of the system.

## Grid / container

Containers: `80rem` (800px) prose measure, `107rem` catalog, `110rem` (`.wide`) maximum, `90rem` specs. Grid columns observed: `1`, `2`, `3`, `4` — there is no universal column base; each grid declares what it needs. Gaps: `1rem` in the catalog, `0` in the spec grid (the interleaving is done with `order` + offsets, not gutters), `5rem` in the credits row. Mobile (390px): the 3-up catalog goes to 1-up at full card width, the 2-up spec grid goes to 1-up and drops `position` offsets, and body type falls from 28.5px to 13.65px — a **2.1× reduction driven entirely by the `vw` root**, with not one `font-size` media query on a text element.

## Production-safety note

- **Two-layer role tokens + per-section remap** — production-safe, and the highest-value idea on this page. Cost: near zero. It also *fixes* a11y (contrast pairs are decided once per palette, not per component) and makes dark mode nearly free.
- **Chrome adopting section palette** — production-safe. Cost: one IntersectionObserver; must gate the transition (not the color swap) behind `prefers-reduced-motion`, which Playdate does. Verify contrast for *every* (band, chrome) pair — the mechanism guarantees consistency, not legibility.
- **`vw`-driven root font-size** — **spectacle-only for text-heavy or app UI.** Cost: it defeats the user's browser font-size setting, a WCAG 1.4.4 concern. Safe pattern: use it for a brand page with a hard cap (Playdate stops at 1100px), or restrict the `vw` term to a `clamp()` on non-text dimensions and let type stay in `rem`.
- **Infinite ambient loop (`blobble`)** — production-safe **only** with the reduced-motion gate the original omits. Cost: an always-running compositor animation (battery), and vestibular risk if scaled up beyond a few percent.
- **WebGL device + rAF** — spectacle-only. Cost: ~953 rAF calls per scroll pass, a live GL context, no off-screen pause. Always ship the `<video>` → PNG ladder underneath.
- **A11y scorecard (captured, honest):** **Alt coverage 1.0** (14/14 images) and the wordmark is a real `<h1>` with visually-hidden text — both good. **Reduced motion partially respected**: three authored `prefers-reduced-motion` blocks plus a `body.reduce-motion` user toggle (rare and commendable), but the infinite blob loop ignores it. Defects: (1) **41 of 85 interactive targets fall under ~44px** — the 24-link nav is the main offender; (2) **no authored `:focus-visible` styling**, and the newsletter `<input>` actively clears its focus border; (3) `--subtle` grey `#7a8085` on the `#efefef` band is ≈ 3.4:1 — fine for large text, **fails AA for body copy**; (4) `image-rendering: pixelated` game art carries meaning that no `alt` conveys beyond the title. Net: the color system is excellent, the motion is restrained and mostly gated, and the misses are all in *controls* — focus and tap targets — not in spectacle.

## Extracted patterns

- section-palette-handoff — full-bleed color bands that re-point semantic role tokens, with a fixed header that inherits the palette of whichever band it is over; reuse for long marketing pages, themed editorial chapters, and any transparent nav floating over unpredictable content.
- blob-cluster-idle-wobble — an organic idle animation built from one non-uniform-scale keyframe shared across N elements with de-synchronised durations and delays; reuse for ambient hero atmospherics, mascot idles, and loading states.
