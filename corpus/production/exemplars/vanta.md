## What works (transferable principles)

- **A high-contrast serif display over an all-sans UI is the entire personality, bought with one extra font.** Every large headline (`Trust is everything`, the pull-quote, `Meet the new standard for trust`) is a Reckless-class serif; literally everything else — nav, body, labels, buttons, the product mock — is Inter. The serif reads warm, editorial, "trusted institution"; the sans reads precise, "software." Pairing them lets a compliance/security product feel human at the headline and exacting in the chrome. Transfers to any B2B brand that wants gravitas without going corporate-stiff: reserve a serif for display only, keep one sans for all functional text.

- **Sectioning by changing the *canvas color*, not by adding dividers or shadows.** The page is a deliberate sequence of full-bleed bands — lavender hero (`#ddd6ff`) → white/`#f7f8fa` feature bento → near-black `#21222f` narrative ("Built for you", the persona quote, the resource cards) → lavender again → deep-purple footer (`#260048`). Each band switch signals "new chapter" with zero ornament. Whitespace + the color change do all the separating, so a ~10k-px page never feels like a stack of boxed sections. Transfers to any long landing page: pick 3–4 canvas tones and alternate them; drop the hairline dividers.

- **A tinted "rest" canvas, not white, frames the hero and CTA — so brand color appears even before any accent is spent.** The hero and footer sit on lavender rather than the default white. Because the field is already softly chromatic, the page feels owned/branded immediately, and the single saturated violet CTA (`#5e05c4`) still pops against it. Transfers anywhere you want warmth without loud color: tint the largest background regions a few percent toward the brand hue and keep accents for interactive elements only.

- **The product is sold as a live, in-product mock — chat threads, progress bars, real framework chips — not an abstract illustration.** The hero embeds a faux Vanta workspace ("Thinking… Connecting AWS", an `ISO 42001` checklist with a green progress bar); later sections show an AI-agent chat and a real-looking risk matrix. For software, showing the actual interface doing the job builds more trust than a hero graphic. Transfers to any SaaS: render a believable slice of the app (with motion-suggesting states like "Preparing", partial progress) as the hero visual.

- **Bento grid where every tile is a different *concept*, unified only by a shared card shell.** "It's all here" is a 2×3 of Compliance / Risk / Third-Party Risk / Audit / Trust Center / Questionnaire Automation — each tile holds a distinct mini-UI (a SOC-2 card, a heat-map matrix, a vendor table, a framework grid). Variety inside the tiles communicates breadth of product; the identical radius/padding/surface keeps it from looking chaotic. Transfers to any "platform / all-in-one" pitch: let tile *contents* differ wildly, lock tile *frames* identically.

- **Hierarchy from scale + family contrast, never from heaviness.** Display serif runs ~42–60px while body sits at 16px (a ~3–4× jump) and the heaviest weight on the page is ~600. The size leap and the serif/sans switch carry the emphasis, so the page stays calm and legible even where information is dense. Transfers broadly: when you need a headline to dominate, scale it up and/or change its family — don't reach for bold.

- **One accent, one semantic, everything else neutral.** Violet `#5e05c4` is the only saturated brand color (CTAs, key icons); green is the only semantic, and it lives exclusively in the product mock's progress/status UI (`#0b885b` on `#a4f4cf`). The rest is ink/grey/lavender. Rationing color this hard means the violet always means "act" and the green always means "compliant/done." Transfers to any product UI: assign each saturated hue exactly one job.

## Design-system read

- **Type:** Two families with split duties — **Inter Variable** for all UI/body, **Reckless** (serif) for display headlines + the pull-quote. Scale is an 8-step ramp (12/14/16/18/22/30/42/60px) but the *gap between 16px body and the 42–60px serif display is the hierarchy*; mid-sizes are sparse. Weights only 400/500/600 — no true bold. Body leading generous (24px on 16px = 1.5), display near 1.0–1.1. **Tracking is set in near-constant pixels, not a constant em** — captured: the 72px h1 and 56px heads carry `-1px`, while 64/42/30px sit at `-0.5px` and 20px barely tightens (`-0.05px`); body is ~0. Because the absolute offset is held roughly flat (`-0.5`/`-1px`) across very different sizes, the *em* value actually shrinks as type grows (72px·-1px ≈ -0.014em vs 30px·-0.5px ≈ -0.017em) — so don't model it as one tracking-tight token; tighten by a small fixed px on display and leave body/UI near-normal.
- **Color:** A **dual/multi-canvas** system, not a single background. Neutrals: ink `#181822` → slate `#484960` → muted `#6d6e87` → subtle `#9e9fb7`; surfaces white → `#f7f8fa` → `#e3e0eb`. Brand canvases: lavender `#ddd6ff` / `#cdd2f8`, deep purple `#260048`, and a near-black narrative band `#21222f`. Exactly one accent (violet `#5e05c4`, soft `#ba9dff`) and one semantic (green `#0b885b`/`#a4f4cf`). Amber `#f9c71c` appears once as a sparkle accent.
- **Spacing rhythm:** 8px base. Tight intra-component cluster (4/8/12/16px gaps), generous section padding (32→64→80px), and big 128px breaks between bands. Air is the primary separator.
- **Layout system:** Centered container (~1200px content) inside full-bleed colored bands. Repeating geometries: centered hero (headline → subcopy → inline email+CTA pill → product mock), 3-up and 2×3 bento grids, a 3-column "audience" block, 4-up resource cards, and a 7-column footer. Captured at 1440×900; mobile (390w) collapses bento to a single column and the multi-col footer to stacked groups, and keeps the inline email+button as one pill, though the serif display headline scales down (h1 ~72→48px).
- **Motion / easing intent:** Restrained, but **library-driven** (GSAP + ScrollTrigger + Webflow IX2 — not hand-rolled). Captured params: durations cluster at **100 / 150 / 200 / 300 / 350ms** for micro/hover/state, stretching to **400 / 700 / 1000ms** for reveals and the count-up-style progress fills. Easings are the house `ease` (the overwhelming default, ~245×) plus three bespoke curves — `cubic-bezier(0.645,0.045,0.355,1)` (in-out cubic), `cubic-bezier(0.455,0.03,0.515,0.955)` (in-out quad), and the in-only `cubic-bezier(0.55,0.085,0.68,0.53)` — used for the scroll-linked reveals and SVG settles. No measurable stagger delays (the SVG groups settle together, not in sequence). Motion communicates responsiveness and the "live product" feeling (progress bars, thinking states, settling diagrams), not spectacle. Full choreography in **Interaction & motion** below.
- **Density:** Medium-high. The embedded mock UIs and the vendor/risk tables are genuinely dense, but the surrounding marketing chrome is sparse and high-contrast, so nothing feels cramped.
- **Hierarchy:** Dominant ordering device is **scale + family contrast** (serif display vs sans body), reinforced by canvas value (light vs dark bands) and centered position in the hero.
- **Restraint:** No gradients on text, no rainbow of accents, no shadow-heavy cards (surfaces are flat; separation is canvas color), no competing weights, no decorative illustration where a real UI mock can do the job.
- **Grid / container:** Re-probe measures columns **1 / 2 / 3 / 4** on desktop, with a **measured centered ~1280px content container** (nav/mock span ≈80→1360px; the 640px value is a single bento panel, 1120px an inner inset) inside full-bleed colored bands and a **~16px tile gutter**; the feature section is a 3-up / 2×3 bento, the audience block 3-column, resource cards 4-up, footer 7-column. On mobile (390w) the grid collapses to a single column (capture also shows a 4-up reordering to a stacked sequence) and the multi-col footer stacks into groups. (The 4-up resource row is now in the column probe; only the 7-col footer remains **frame-estimated**.)
- **Components** (resting → state deltas, from `.craft.states` + hover probe):
  - **Button (primary CTA):** violet `#5e05c4` fill, white label, pill radius, often with a trailing circular arrow affordance. *Disabled:* stays full `#5e05c4` at `opacity:1` with `cursor:default` (Vanta does **not** dim the disabled CTA — it signals unavailability by cursor, not by fade; flag for a11y — there's no visual disabled affordance).
  - **Nav item / dropdown trigger:** resting bg `rgb(249,249,249)` border `rgb(195,196,211)`; *hover:* a near-imperceptible bg→`rgb(248,248,249)` / border→`rgb(192,192,208)` shift (a ~1-value nudge — the hover feedback here is deliberately subtle, almost a no-op). *Focus:* `2px` outline `rgb(46,55,124)` (the deep indigo focus ring).
  - **Link / generic `<a>`:** *focus:* `1px` outline `rgb(16,16,16)` (near-black) — focus-visible is present site-wide.
  - **Card (bento tile):** flat surface, identical radius/padding across tiles, no hover lift captured — separation is canvas + 16px radius, not shadow; the only real elevation is a `0 0 30px 3px rgba(0,0,0,0.15)` diffuse glow reserved for the floating product mock.
  - **Input (hero email field):** sits *inside* the CTA pill as one unit (email field + button share a single rounded container); no standalone focus delta captured beyond the global ring.

## Interaction & motion

Vanta's motion is **restrained but genuinely library-driven** — a real GSAP + ScrollTrigger + Webflow IX2 stack (not Attio's hand-rolled CSS). The macro experience is **scroll-choreographed canvas bands**; the micro-motion is SVG diagrams settling and "live product" states (progress fills, thinking dots). Evidence from the capture: **6 `@keyframes`** (`spin`, `vanishTwinkleA/B/C`, `delay-overflow`, `osano-load-scale`), **5 IntersectionObservers over 4 targets** (thresholds 1 / 0.5; rootMargins `150% 0%` & `200px`), **~2449 `requestAnimationFrame` calls** (the GSAP ScrollTrigger ticker), **107 scroll + 23 mousemove listeners**, and **1 `prefers-reduced-motion` block — reduced motion is respected.** Frame deltas s00→s09 read top-to-bottom as: lavender hero w/ live mock → white→lavender bento → dark narrative → pinned serif pull-quote → dark proof wall → lavender CTA → deep-purple footer. Stack: `GSAP` · `ScrollTrigger` · `Webflow IX2`. (Note: 8 raw "pin" entries exist but most are cookie-banner / nav-bar fixed-position noise — only the pull-quote pin and the path-draw box are real content motion.)

- **Alternating-canvas band choreography** — *Trigger:* scroll-progress. *Mechanism:* full-bleed sections swap canvas value as you scroll (lavender → white → dark `#21222f` → lavender → deep-purple), with the nav bar and a couple of containers held `position:fixed/sticky` by ScrollTrigger so the bands slide under stable chrome. *Reads as:* a long page reading as distinct "chapters" by color, with no dividers. *Transfers to:* any tall landing page that needs sectioning without ornament. *Safety:* **production-safe** (native sticky + value swaps; the choreography is just which band is in view). → `sticky-pin-scrollytelling`, `alternating-canvas-bento`.
- **Scroll-linked canvas warm** — *Trigger:* scroll-progress. *Mechanism:* the "It's all here" bento section animates its background from `rgb(247,248,250)` (`#f7f8fa`, near-white) to `rgb(205,210,248)` (`#cdd2f8`, lavender) as it scrolls — a measured `background` interpolation, not a hard band cut. *Reads as:* the feature grid "warming into" the brand color, a soft handoff between a white chapter and the next lavender one. *Transfers to:* any section transition you want to feel like a dissolve rather than a seam. *Safety:* **production-safe** (background-color tween; cheap, meaning isn't hue-dependent). → `scroll-linked-recolor`.
- **In-view SVG scale-settle** — *Trigger:* in-view (IO, 4 targets, threshold 0.5 / rootMargin `200px`). *Mechanism:* the bento mini-UI graphics (`<g>` groups: the SOC-2 card, risk heat-map, vendor table) enter slightly enlarged and ease to rest — captured scales **1.08→1, 1.12→1, and 1.426→1** — paired with an opacity resolve (`1.00→0.19` on one group is a layered fade within the diagram). *Reads as:* each product diagram "snapping into place" as its tile arrives — life without bounce. *Transfers to:* any in-view product screenshot / chart you want to feel placed rather than static. *Safety:* **production-safe** (compositor-only `transform`/`opacity`, fires near-once; keep the start scale modest — 1.43 is the upper bound here). → `scroll-scale`.
- **Sticky-pinned serif pull-quote** — *Trigger:* scroll-progress. *Mechanism:* the large Reckless testimonial ("Vanta helped us unblock our sales cycle…", GitHub) is held `position:sticky` (the real `p.` pin in the capture) so the quote stays centered while its lavender band scrolls through. *Reads as:* scrollytelling — one claim held while the eye reads it. *Transfers to:* testimonials, single big claims, manifesto lines. *Safety:* **production-safe** (native sticky, no JS). → `sticky-pin-scrollytelling`.
- **SVG path-draw on the live product diagrams** — *Trigger:* in-view, then a ScrollTrigger/rAF loop. *Mechanism:* the capture exposes a box commented `/* Prep: animate each path in its own box */` — the workflow/connection diagrams draw their SVG paths in, and a `<g>` parallax-translate + the `1.00→0.19` opacity step animate connection states (the "Thinking… Connecting AWS", progress, agent-chat mocks). *Reads as:* "the product is doing work right now" — the interface IS the pitch, animated. *Transfers to:* any automation / agent / workflow story where the diagram should feel alive. *Safety:* **spectacle-leaning but production-safe if budgeted** — the most expensive thing here (drives much of the 2449 rAF via ScrollTrigger). Lazy-init on in-view, pause off-screen, ship a static SVG under reduced-motion. *(No standalone snippet — bespoke to the content; reuse the principle: draw/animate the real product graph, gated + pausable.)* → `patterns_to_build: svg-path-draw-diagram`.
- **Twinkle sparkle loop** — *Trigger:* load (ambient). *Mechanism:* the amber `✨` in the announcement bar ("Vanta Delivers: AI is moving fast…") loops via `vanishTwinkleA/B/C` keyframes (staggered three-phase fade/scale) plus a `spin`. *Reads as:* a tiny "new / AI" shimmer that draws the eye to the banner without motion-sickness risk. *Transfers to:* announcement bars, "new" badges, AI-feature flags. *Safety:* **production-safe** (a 1-char decorative loop; gate under reduced-motion since it's continuous). → `patterns_to_build: twinkle-sparkle-accent`.

## Production-safety note

This is a live, conversion-optimized B2B site — all techniques are **production-safe**:
- Serif-display + sans-UI pairing: **production-safe**, ~one extra webfont. Cost: load the display serif via `font-display: swap` and subset it (it's used on few, large strings) to avoid CLS on the hero.
- Alternating full-bleed canvas bands: **production-safe**, zero perf cost; just verify text contrast *per band* (ink on lavender `#181822`/`#ddd6ff` ≈ fine; check muted greys on the `#21222f` dark band meet 4.5:1 — use `#ffffff`/light for small text there).
- Tinted hero canvas + single violet CTA: **production-safe**; confirm `#5e05c4` button text (white) and the violet-on-lavender focus ring clear 4.5:1.
- Live product-mock hero: **production-safe** but a **payload watch** — these are large composite images/DOM; ship responsive `srcset`/AVIF (or render as real lightweight DOM) and lazy-load below-fold mocks on a ~10k-px page.
- Bento with heterogeneous tile contents: **production-safe**; the discipline is keeping the *frame* tokens identical — the variety must live only inside the tiles.
- **A11y (captured, honest):** **Strong** — `img_alt_ratio: 1.0` (all 70 images carry alt text), **focus-visible present** site-wide (near-black `1px` ring on links, `2px` indigo `rgb(46,55,124)` ring on nav controls), and **`prefers-reduced-motion` respected** (1 PRM rule, GSAP timelines gated). **Two real defects:** (1) **tap targets** — ~**82 of 281 interactive elements are under 44px** (≈29%); tighten footer links / icon buttons / nav chevrons for touch. (2) **Disabled CTA gives no visual affordance** — it stays full violet at `opacity:1`, signaling unavailability only via `cursor:default`; add a dim/desaturate or label so non-pointer users can perceive the disabled state. **Dark mode:** not supported (`supportsDark: false` — the page is light/branded only; the "dark" bands are content canvases, not a theme).

## Extracted patterns

- **serif-display-on-tinted-canvas** — the hero/CTA pattern: an oversized serif headline + sans subcopy + inline email-and-button pill, all centered on a softly tinted brand canvas. Reuse to open a B2B landing with warmth and immediate brand presence.
- **alternating-canvas-bento** — a feature section built as a uniform-shelled bento grid sitting on its own full-bleed canvas band, where each tile carries a distinct mini-UI. Reuse to pitch an "all-in-one platform" and to chapter a long page by background color.
