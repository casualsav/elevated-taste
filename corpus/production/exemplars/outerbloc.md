## What works
- **Three typographic registers, each with one job.** A light serif (Larken) carries every editorial headline, a heavy grotesque (TWK Lausanne) carries the brand wordmark and UI, and a tracked uppercase mono (Geist Mono) carries all metadata (eyebrows, section kickers, role labels, card spec-lists). Because face — not size or weight — signals which voice you're reading, the page sorts message / identity / annotation pre-attentively and stays calm at high density. Transfers to any content-led brand site that wants editorial warmth plus system-y labeling.
- **The brand name as architecture, not a logo.** The wordmark is set so large it bleeds off both screen edges (you read a fragment), opening the hero and closing the footer. It conveys scale and confidence with pure type and zero color/imagery, and bookends the page without a logo lockup. (See `edge-bleed-wordmark-masthead`.)
- **Warm monochrome inversion instead of accent color.** The whole site is one warm bone (`#f6f7f3`) and one warm near-black (`#1c1a16`); "primary" sections are signaled by *inverting* to the dark surface, not by adding hues or weight. Surface inversion does the emphasis that color usually buys, keeping the palette to two values.
- **Notched concave section transitions.** Dark and light bands meet on a large concave rounded corner so panels appear to lift away from each other, giving structure without rules or shadows. (Already in corpus as `notched-section-transition`.)
- **Restraint as the system: no shadows, ever.** Cards, panels, and the email pill are all flat — separated by radius, hairline tint, or surface value, never elevation. Flatness keeps embedded work thumbnails (the only real texture/color on the page) as the focal points.
- **Ambient social proof via a top ticker.** A slow news marquee drip-feeds client/press wins above the masthead — credibility absorbed peripherally, costing no vertical space. (See `announcement-ticker-marquee`.)

## Design-system read
- **Type:** Three families, ~8× range (label ~11px → wordmark ~90px+, bleeding far larger via clipping). Larken serif light (~300) for display/headlines; TWK Lausanne grotesque (300/400/500) for the wordmark + body UI; Geist Mono uppercase, ~0.8px tracking, for all labels. Hierarchy = **typeface + scale**, near-regular weight throughout. **Tracking is size-dependent, not one constant em:** it tightens proportionally as display type grows — measured ~**-0.03em** on serif headlines (60px → -1.8px, 52px → -1.56px, 35px → -0.7px), eases toward **-0.01em / -0.02em** on mid sans (15px → -0.15px, 16px → -0.32px), and *inverts to positive* on the small mono labels (**+0.06em**, 14px → +0.84px; 11px → +0.22px). So: tighter-as-bigger on the serifs/sans, deliberately *loosened* on the uppercase mono metadata.
- **Color:** Two-value warm monochrome — bg bone `#f6f7f3`, ink warm near-black `#1c1a16` (deliberately not pure black). Dark sections reuse the same ink as background with bone text (true inversion). The only chroma is a near-default browser link blue (`#0000ee`, brighter `#0e8ef0` on the email pill) used on a few links — an intentional "honest/unstyled" accent. Roles: bg / surface(white cards) / fg / muted(`~#6b6a64`) / accent(link-blue) / bg-dark(inverted).
- **Spacing rhythm:** 5px base grid; common steps 5/10/15/20/30/40/60/100px. Generous vertical air around the serif headlines and wordmark; sections separated by large empty bands so density never feels crowded.
- **Layout system:** ~1440 desktop frame; centered editorial column for headlines, a 3-up service-card row, a 4–5-up logo/work grid, and a split (serif headline left / mono proof-stats right). Collapses to a single column on mobile with the wordmark still bleeding off both edges. Radii are large and soft (13/25/30px panels, full-pill controls).
- **Motion / easing intent:** Captured params are spare — two durations only, **300ms** (`ease`, the default hover/state) and **400ms** with `cubic-bezier(0.44,0,0.56,1)` (a symmetric in-out for emphasis); a stray **100ms** for the quickest flips. **No stagger** is configured (`stagger_delays_ms: []`). Despite the calm vocabulary the runtime is busy: Framer-driven, **120 IntersectionObservers** (many with dense `[0,0.01…0.99]` threshold arrays = scroll-*scrubbed*, not one-shot), **1765 rAF callbacks** on a scroll pass, 4 scroll + 5 mousemove listeners. So the *intent* reads ambient, but the *implementation* scrubs transforms continuously — see **Interaction & motion** for the choreography and its cost.
- **Components:** Sparse capture — the site exposes almost no styled interaction states. **Button (CTA pill):** the only real hover is `Let's Talk`, which swaps fill from ink `#1c1a16` → link-blue `#0e8ef0` over ~300ms `ease` (a hue jump, not a lift — consistent with the flat, shadowless system); resting is a full-pill ink button with white label + ↗ glyph; **no disabled state captured.** **Card (work tile / white CTA card):** flat, one shared radius (~13px), separated by surface value + gap, **no hover lift/border-shift captured** (the tiles are links but rely on the thumbnail itself for affordance). **Nav:** 7 text links, ink default; no distinct hover delta captured beyond the global focus outline. **Input (email pill):** flat full-pill field, link-blue accent (`#0e8ef0`); no focus/error delta captured. *Net: hover styling is essentially limited to the primary CTA; everything else leans on the resting form.*
- **Grid / container:** ~1440 desktop frame; the re-probe measures a clean **3-column** work/service grid (three ~403px tiles in a centered **~1290px** band with ~75px outer margins on the 1440 frame) with **~40px** gutters (8×the 5px base — corrects the earlier ~10–15px estimate). Collapses to **1 column** at 390 mobile. No real max-width — the wordmark/hero bleed edge-to-edge (full-bleed ~1600–1800px candidates), so only the work grid is bounded to the ~1290px band; the headline column is left-aligned and narrower than the full grid.
- **Density:** Low-to-moderate and airy; the only dense moment is the work grid, which stays legible because every tile shares one radius/gap and the cards are flat.
- **Hierarchy:** Dominant ordering device is **scale + typeface** (giant grotesque mark → serif headline → mono label → sans body), reinforced by surface inversion for section weight.
- **Restraint:** No gradients, no drop shadows, no hero illustration, essentially no accent color beyond raw link-blue. Emphasis is bought with face, scale, and bone/black inversion only.

## Interaction & motion

Built in **Framer**, so there are **zero authored `@keyframes`** (`keyframeCount: 0`) — every effect is JS-driven through Framer's runtime: **120 IntersectionObservers** (most carrying dense `[0,0.01…0.99]` threshold arrays, i.e. scroll-*scrubbed* not fire-once) and **1765 rAF** callbacks per scroll pass. The vocabulary is small (rotate / scale / parallax / fade) and the *intent* is ambient, but the technique is genuinely scroll-linked, not just in-view reveals. **Reduced motion is NOT respected** (`respectsReducedMotion: false`, 0 PRM rules) — a real defect given the continuous rAF scrubbing. Evidence below is grounded in the frame deltas s00→s09 and the probe counts; from==to representation noise was dropped.

- **Scroll-scrubbed orbital line-marks** — *Trigger:* scroll-progress. *Mechanism:* a cluster of ~16 small Framer sub-elements each rotate to ~**-241°** as their section's scroll progress advances (the blue/orange/green geometric service icons that enter in s03 — each is an orbiting ring of squares around a center glyph). *Reads as:* the decorative spec-icons feel hand-wound and reader-driven, adding the only kinetic color on an otherwise still page. *Transfers to:* decorative section markers, "live" logo/diagram bugs, any orbital/badge ornament. *Safety:* **production-safe with care** — compositor-only `transform: rotate`, but cap the angle and gate it; a -241° scrub with no reduced-motion fallback (as shipped) is the kind of thing to fix. → `scroll-progress-rotate`.
- **Scroll-scrubbed scale-up reveal** — *Trigger:* scroll-progress. *Mechanism:* the `COPY` / `PASTE` demo tiles scale from **0.5 → 1.0** as they scroll into place (paired with a 0→1 opacity fade), driven by the dense-threshold IO arrays. *Reads as:* a small "snap into existence" beat on the clipboard/process demo — emphasis without a shadow or color change. *Transfers to:* product-step tiles, before/after chips, any element you want to "pop" on entry. *Safety:* **production-safe** (transform+opacity only; ship a static end-state under reduced-motion — which this site omits). → `scroll-scale`.
- **In-view fade-in** — *Trigger:* in-view. *Mechanism:* opacity 0→1 on intersect (`COPY`/`PASTE` and the entrance container at `firstChangeAt: 300ms`, 0.02→0.87), one-shot, ~300ms. *Reads as:* the page settles in section-by-section rather than appearing all at once. *Transfers to:* any tall editorial/portfolio page. *Safety:* **production-safe** (GPU-cheap, one-shot). → `scroll-reveal-in-view`.
- **Subtle parallax drift** — *Trigger:* scroll-progress. *Mechanism:* a few elements translate at a rate offset from scroll (the top news ticker `ul`, the "NEW website for Lumos…" ticker item, a hero container). *Reads as:* mild depth between the masthead layers and the ticker; not a heavy parallax stage. *Transfers to:* mastheads, sticky-ish header bands, ticker rows. *Safety:* **production-safe (subtle)** — keep the displacement small and transform-only; becomes motion-sickness-prone if amplified. → `parallax-drift`.
- **Count-up stats** — *Trigger:* in-view (inferred). *Mechanism:* the headline metrics `150+` and `$100M+` (s03) read as figures that tick up when the stat band enters; rendered with `tabular-nums` so the digits don't jitter. *Reads as:* momentum / proof, the numbers "earning" themselves. *Transfers to:* any results/metrics band. *Safety:* **production-safe** (text only; show the final value immediately under reduced-motion). *Frame-inferred* — the band is present and tabular-nums is set, but a discrete count animation wasn't isolated in the scroll-diff. → `count-up-stat`.
- **Continuous announcement ticker** — *Trigger:* load (autonomous). *Mechanism:* the top news strip crawls horizontally on a continuous loop (visible across s00; client/press wins). *Reads as:* ambient social proof absorbed peripherally. *Transfers to:* press/wins strips above a masthead. *Safety:* **production-safe with conditions** — must pause on hover/focus, honor reduced-motion (this site does not), and never lock real info solely inside the autoscroll. → `announcement-ticker-marquee`.
- **CTA hue-swap hover** — *Trigger:* hover. *Mechanism:* the `Let's Talk` pill swaps fill ink `#1c1a16` → link-blue `#0e8ef0` over ~300ms `ease` (no lift, no shadow — flat system). *Reads as:* a crisp, honest state change matching the "unstyled blue" accent language. *Transfers to:* primary CTAs in a flat/shadowless system. *Safety:* **production-safe** — but pair the hue change with the existing label/↗ affordance so the action isn't signaled by color alone.

**Patterns to build:** none required — every technique above maps to an existing recipe. The *scroll-scrubbed -241° rotation* is a more aggressive cousin of `scroll-progress-rotate` (which caps the angle); if a "full orbital scrub" recipe is ever wanted it'd be a new `scroll-orbit-scrub` pattern, but it is **not** faked into `patterns:` here.

## Production-safety note
- **edge-bleed-wordmark-masthead — production-safe with conditions:** overflow must be `clip` (never a horizontal scrollbar); the visible fragment must still read as the name; keep the true name in the DOM (`aria-label`) for a11y/SEO. Only viable for short, high-contrast names.
- **announcement-ticker-marquee — production-safe with conditions:** decorative motion — must honor `prefers-reduced-motion`, pause on hover/focus, and never lock real information solely inside the autoscroll. Translate-based only.
- **Warm monochrome + flat (no shadow):** fully production-safe and cheap; just verify muted text and the link-blue clear AA on the bone background.
- **Notched transition / carousel:** production-safe; give the carousel real controls and visible focus.
- **Scroll motion (Framer):** the scrubbed rotate/scale/parallax effects are transform/opacity-only and cheap *per element*, but the page ships **120 IntersectionObservers + ~1765 rAF/scroll pass with NO reduced-motion gate** — borrow the *techniques*, but always add a `prefers-reduced-motion: reduce` fallback (jump to end-state) and pause off-screen work, which this site does not do.
- **A11y (capture, honest):** `img_alt_ratio: 1` — **every image has alt text** (the one genuinely strong a11y trait). Defects: `focus_visible: false` — focus is a global 1px `rgb(16,16,16)` `:focus` outline, **not** `:focus-visible`, so it shows on mouse click too (acceptable but blunt; it does at least exist and contrasts on bone). `reduced_motion: false` — **reduced motion is not respected** despite heavy scroll scrubbing. **Tap targets:** 15 of 16 interactive elements measured below the 44px target (the small ticker links and inline controls) — fine on desktop, **fix for touch** before reuse. No dark-mode variant (`supportsDark: false`; the dark sections are inverted surfaces, not a theme).

## Extracted patterns
- `edge-bleed-wordmark-masthead` — short brand name set past the viewport so it clips at both edges; reuse as a confident, image-free brand hero/footer sign-off.
- `announcement-ticker-marquee` — top-pinned looping news strip; reuse for ambient social proof (client wins, press, releases) without spending vertical space.
- `scroll-progress-rotate` — transform rotation bound to scroll progress; here it spins the orbital service-icon ornaments. Reuse to make a decorative badge/diagram feel reader-driven (cap the angle + gate it — unlike this site). (motion)
- `scroll-scale` — element scales (0.5→1) with scroll progress on entry; reuse to "pop" a step/demo tile without a shadow or color change. (motion)
- `scroll-reveal-in-view` — IntersectionObserver-gated opacity 0→1 that fires once; reuse to give a tall editorial page entrance rhythm. (motion)
- `parallax-drift` — layers translate at offset rates with scroll; here a subtle masthead/ticker depth. Reuse sparingly (transform-only, small displacement). (motion)
- `count-up-stat` — figures tick 0→value when in view, `tabular-nums` so digits don't jitter; reuse for a results/metrics band. (motion)
