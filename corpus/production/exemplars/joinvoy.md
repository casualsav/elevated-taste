## What works (transferable principles)

- **One deep-green ground + a warm off-white ink ramp carries an entire studio site with almost no "card" surfaces.** The page lives on near-black forest green (`#001a0b` body, `#001207` footer, `#000a04` html) with warm-white text (`#e8ede2`) and a muted sage for secondary copy (`#9aaa99`). There is no light "content card" layer — sections are transparent and sit directly on the green field, separated only by whitespace. Saturated hues (lime `#d5e96d`, coral `#ff623b`, plus pink/yellow/chartreuse "stickers") appear only as *punctuation* — a 5px coral nav dot, a focus ring, a sticker tag, the self-drawn product art. Transferable: pick one near-black chromatic ground (not pure black — the green undertone warms everything), give text a 2–3 step off-white→sage ramp, and ration every saturated hue to tiny signals so the field stays calm.
- **Hierarchy is pure scale contrast in a single *light* weight — nothing is bold.** Display headlines are serif at **weight 300–400** scaled to `clamp(30–120px)` (principles) and up to `131px` (about), set against 10px uppercase labels tracked to `0.22em`. That is a ~12× size jump with *no* weight change; the thin serif at huge size reads as confident, not loud, and whitespace does the separating. Transferable: reach for size + a lighter display weight before bold; a hairline-thin serif at display scale feels editorial and premium where a heavy weight would feel shouty.
- **A three-family type system splits roles, and section-scoped CSS variables re-point the *same* token at different fonts.** `--serif` and `--sans` are redefined per section (`#about { --serif:'Season Mix'; --sans:'NB International Pro' }`, hero/testimonials likewise) so one set of utilities drives Spectral-or-Season-Mix for editorial display and Manrope-or-NB-International for UI/labels/body — without new classes. Serif = warmth and voice; grotesque sans = system/labels/body. Transferable: address typography through role tokens (`--serif`/`--sans`) and override those tokens at the section scope to shift mood contextually; you get per-section personality from the cascade, not a parallel class tree.
- **Product demos are drawn entirely in CSS — no screenshots.** The "Work" bento tiles are a supplement bottle, a highway billboard, and a running-app phone built from gradients and pseudo-elements (`.bottle-body` layered inset shadows, `.billboard-poster` radial "sun", `.phone` with a `.progress-ring` conic-ish bordered ring and a spinning `.play-orb` radial gradient). Transferable: for brand/feature illustration, hand-build the mock in CSS instead of shipping a flat PNG — it stays crisp at any density, re-themes with your tokens, weighs nothing, and signals craft. (Note cost: it is labor-intensive and a11y-opaque; give each tile a text label.)
- **Generous vertical rhythm makes high information density read calm.** `section-space` is `150px` block padding; eyebrow-to-content gaps run 56–110px; the principles list breathes at `47px` per row. The page stacks a draggable hero, an about statement, a logo marquee, seven principles, a testimonial carousel, a six-tile work grid, a recruiting orbit, and a giant wordmark footer — yet never feels crowded because the air between blocks is enormous and the palette never competes. Transferable: when a page carries many sections, buy calm with large, *consistent* section padding and a monochrome field rather than dividers or boxes.
- **Accessibility is treated as first-class under heavy decoration.** Full keyboard story: a lime skip-link, `focus-visible { outline:2px var(--lime); outline-offset:6px }` on every control, 100% image alt coverage, `tabular-nums` on counters, and — critically — **21 `prefers-reduced-motion` rules plus `body.motion-paused`** that disable every reveal, marquee, orb, and word-mask and jump to the end state. Transferable: a decoration-heavy page can still be inclusive if every animated class carries a reduced-motion/no-JS off-ramp and focus states use a high-contrast signal hue.

## Design-system read

- **Type:** Three families, role-split. **Display serif** — Spectral (`--serif`, hero/principles/testimonials) and Season Mix (`#about`), weight **300–400**, huge: about `clamp(42px,5.775vw,131px)`/lh 1.04/tracking −0.035em, principles `clamp(30px,5.56vw,120px)`/lh 1.13, blockquote `clamp(30px,3.34vw,48px)`/tracking −0.045em, join `clamp(50px,5.5vw,80px)`/tracking −4px. **UI/body sans** — Manrope + NB International Pro, body 14px, nav 15px (−0.5px). **Labels** — uppercase sans, 10–18px, tracking `0.22em`/`4px`. Hierarchy = scale contrast (≈12×) at near-constant light weight; tracking is size-proportional (tight-negative on big serif, wide-positive on small caps). Fluid `clamp()` throughout; `font-variant-numeric: tabular-nums` on numerals.
- **Color:** Monochrome green spine — ground `#001a0b`, deep `#001207`, page `#000a04`; ink `#e8ede2`, muted sage `#9aaa99` / `#b8c6b9`; hairline `rgba(228,238,221,.2)`. Accents rationed: lime `#d5e96d` (focus ring, selection, skip-link, play-orb), coral `#ff623b` (active-nav dot, visitor cursor), plus sticker hues pink `#f2dbf1` / yellow `#efd85d` / chartreuse `#c0df16`. Selection flips to `lime on bg`. No light re-theme — the page is natively dark; only the *modals* and CSS mock tiles use light fills for contrast.
- **Spacing rhythm:** ~8px base with a generous macro scale. Section padding `150px` (→110 @1100, →90 @700); eyebrow margins 56–110px; grid gaps 16/24px; marquee gap 85px. Micro-padding inside pills/chips (6–16px). The contrast between tight component padding and vast section air is what reads as "designed."
- **Layout system:** Center-stack, full-bleed sections on a ~1296–1320px max track (testimonials/dialog), content otherwise edge-padded `4.5%`. Flex-dominant (39 flex vs 12 grid). Work is a 5-col bento (`repeat(5,minmax(0,1fr))`, 16px gap, 35px radius, 500px tall) collapsing to 2-col @700. Testimonials a 2-col grid (`0.9fr 1.1fr`, 8% gap). Breakpoints 360→1700; principle preview hidden on mobile; nav stays inline (no hamburger) and wraps.
- **Layering / page architecture:** Not a parallax world — `has_static_backdrop:false`, `has_blend_overlay:false`. Depth is local and choreographed: a **fixed glass-nav pill** (`backdrop-filter:blur(16px)`, inset highlight shadows, 999px) floats top-center; the **hero is a draggable canvas "world"** of image tiles with pointer parallax (`--hero-pointer-x * --pointer-depth`) that fades out (`--hero-opacity`) and blurs away on scroll via a top/bottom gradient mask; a **pointer-following preview thumbnail** (`position:fixed`) appears beside hovered principle rows; the Work block uses one `position:sticky` pin; the Join block orbits avatar chips around a center. Sections are transparent (89% transparent height) but there is no moving backdrop beneath — they reveal only the flat green ground.
- **Motion / easing intent:** Signature easing `cubic-bezier(.22,1,.36,1)` (expo-out) for reveals/settles; `0.25,0.46,0.45,0.94` for eyebrow letters; default state transitions `0.2–0.3s ease`. Reveal durations run long (0.8–1.4s) to feel luxurious. 9 `@keyframes` (`hero-art-in`, `hero-line-in`, `hero-logo-in`, `scroll-pulse`, `marquee`, `quote-in`, `orb-spin`, `principle-backdrop-in`), Lottie for hero art, 13 IntersectionObservers. Intent: **unhurried, editorial entrances; alive-but-calm at rest; fully degradable.**
- **Density:** High apparent density (8 distinct section archetypes, a 6-tile work grid, a carousel, an orbit) held legible by the monochrome field + huge section padding — color never competes, so the eye reads one block at a time.
- **Hierarchy:** Dominant ordering device is **scale** (display serif vs micro-caps), reinforced by **position** (centered single-column flow) and **color** only for tiny active/focus signals.
- **Restraint:** No gradients across large areas (gradients only *inside* the CSS mock art), no drop-shadowed content cards, no second display weight, no light theme, no hamburger. Accent hues never fill a region — they stay dots, rings, and stickers.

## Interaction & motion (techniques)

- **In-view fade-rise-deblur, IntersectionObserver-gated, staggered.** *Trigger:* in-view. *Mechanism:* elements start `opacity:0; translateY(20–35px); blur(4px)` and transition to rest on `.is-visible` (set by IO at thresholds ~0.13–0.25, rootMargin `-25px`/`-100px`); children stagger via `--delay`/`--principle-delay`/nth-child delays. *Reads as:* content settling into place, unhurried and premium. *Transfers to:* any section entrance. *Safety:* **production-safe** — only `transform`/`opacity`/`filter`; reduced-motion jumps to end state. See `patterns/in-view-reveal-stagger.md`.
- **Per-word masked reveal.** *Trigger:* in-view. *Mechanism:* each word wrapped in `.word-mask` (overflow clip) with an inner span translated/blurred up, released on `.is-visible` with per-word delay — the about statement writes itself in. *Reads as:* editorial, typeset-by-typeset arrival. *Transfers to:* hero/section statements. *Safety:* **production-safe**; PRM disables it.
- **Scroll-spy glass nav with active dot.** *Trigger:* scroll-progress / in-view. *Mechanism:* IO on sections toggles `.active` on the matching pill link, which fades in a coral `::after` dot and brightens the label; the pill itself is a fixed `backdrop-filter:blur(16px)` glass capsule. *Reads as:* persistent orientation without a heavy header. *Transfers to:* any single-page site nav. *Safety:* **production-safe**.
- **Pointer-following preview thumbnail.** *Trigger:* hover (pointer). *Mechanism:* a `position:fixed` preview card tracks the cursor (`transform:translate(-50%,-70%)`), fading/scaling in (`.visible`) while hovering a list row. *Reads as:* a lightweight peek/index interaction. *Transfers to:* portfolio/work indexes, link lists, glossaries. *Safety:* **production-safe** — transform-only; hide on touch/reduced-motion. See `patterns/pointer-follow-preview.md`.
- **Draggable hero "world" + card-stack drag with pointer parallax.** *Trigger:* drag + mousemove. *Mechanism:* a canvas world of tiles translates on pointer (`grab`/`grabbing` cursors), with a parallax offset driven by `--hero-pointer-x/y * --pointer-depth`, fading out on scroll. *Reads as:* playful, tactile first impression. *Transfers to:* brand/landing heroes. *Safety:* **spectacle-only** — rAF/mousemove on the main thread (profile shows ~2220 rAF calls); gate behind pointer + reduced-motion and keep a static fallback.
- **Decorative collaborator cursors + logo marquee + orb spin.** *Trigger:* load/loop. *Mechanism:* fake multiplayer cursors drift in the About section (mousemove), a masked `marquee` strip loops client logos (`translateX(-50%)`, paused offscreen), and the play tile's emoji orb spins 28s linear. *Reads as:* "a living studio." *Safety:* marquee/orb **production-safe** (CSS keyframes, paused offscreen, PRM-off); collaborator cursors **spectacle-only** (ambient, no function). 

Reduced motion is respected comprehensively (`prefers-reduced-motion` + `body.motion-paused` + `body:not(.js)` all force end states).

## Production-safety note

- **Production-safe:** in-view reveals, word-mask reveal, scroll-spy glass nav, pointer-follow preview, logo marquee, orb spin, CSS mock art — all `transform`/`opacity`/`filter`, all with reduced-motion and no-JS off-ramps.
- **Spectacle-only:** draggable hero canvas world (main-thread rAF/mousemove cost) and ambient collaborator cursors (decorative, cursor:none override). Reuse only where a brand hero justifies the budget; always keep the static fallback.
