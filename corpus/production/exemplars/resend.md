## What works (transferable principles)

- **A near-pure-black canvas + one rationed violet makes a dev tool feel premium and "lit from within."** The whole page is `#000` with off-white `#f0f0f0` text and grey muting; saturated color appears only as a violet accent (one headline word, code keywords, soft orb glows) and as semantic green/red inside product chrome. Because the field is fully desaturated, the few violet touches read as intentional light, not decoration. Transfers to any technical/AI product wanting a "considered, after-dark" mood: starve the palette, then spend chroma in two or three places.

- **Lead with the actual API as the hero artifact, not an illustration.** The first feature section ("Integrate tonight") centers a real, syntax-highlighted code editor with a horizontal language/framework tab bar (Node.js · Next.js · Remix · Express · Hono · Bun · Astro…). For a developer product the code *is* the value prop and the proof of "first-class DX"; rendering it at editor fidelity earns more trust than abstract art. Transfers to any API/SDK/CLI product — show real, runnable, framework-switchable code above the fold.

- **Two display typefaces split the emotional register of a single page.** A geometric sans carries the workmanlike section headers ("First-class developer experience", "Go beyond editing"), while a Domaine-class **serif** is reserved for the two emotional beats — "Everything in your control" and the closing "Email reimagined. Available today." The serif signals "human / crafted" exactly where the copy turns aspirational; the sans signals "engineering" everywhere else. Transfers to any product story that alternates between technical and emotional sections — let the typeface, not just the words, carry the shift.

- **Mix the two faces *within one headline*, word by word.** The signature move interleaves serif and sans in the same line so individual words flip register ("Everything in your **control**", "Email **reimagined**"). It creates contrast and a focal accent without a second size, weight, or color — purely typographic emphasis. Transfers to hero/section heads that want a "second-read" detail; far calmer than highlighting or bolding.

- **Show the product as embedded, dark-on-dark mini-UIs, not flat marketing cards.** Feature blocks contain real-looking app fragments — a "Delivered/Bounced" log with green/red status, a webhook event feed, the email editor with a Send button, a deliverability stat card (98% / 41%). They sit on barely-lifted near-black surfaces so they melt into the page rather than floating as bright boxes. Transfers to any SaaS: render slices of the real interface tinted to the page, not screenshots in white frames.

- **Semantic meaning via low-alpha tint + colored text, never candy-colored fills.** Status reads as green "Delivered" / red "Bounced" / amber chips over the dark surface using ~12–18% alpha washes with near-saturated text — unmistakable meaning without blocky rows. The same green doubles as the code-string color, so "success" is one consistent idea across UI and code. Transfers to logs, diffs, table status, validation, and analytics on dark themes.

- **Full-pill geometry + an animated gradient-border badge are the only "soft" notes on an otherwise hard, flat page.** Buttons, framework tabs, and the "Announcing Resend Forward" badge are fully rounded; the announcement pill carries a faint green→violet animated border that's the single most colorful element above the fold. One rounded, glowing affordance against flat dark UI reliably pulls the eye to the newest thing. Transfers to changelog/announcement entry points.

## Design-system read

- **Type:** Four families with clear jobs — Inter (body + most headings), ABC Favorit (a few large sans display heads), a Domaine-class **serif** (emotional headlines only), and Commit Mono (code/HTTP logs). Scale is two-cluster: a tight UI ramp (12/14/16/18/20px) and big display jumps (~56/77/96px) with little between — the gap is the hierarchy. Weights stay light (400/500, rarely 600); hierarchy comes from **size + typeface + tracking**, never from going bold. Display tracking is **not one constant em — it tightens hardest in the mid-display band and eases off at the very top:** captured `-2.8px @ 56px` (≈ **-0.05em**, the aggressive sans-display value), but only `-0.96px @ 96px` (≈ **-0.01em**) and `-0.77px @ 76.8px` (≈ **-0.01em**) on the largest heads. So oversized type reads engineered without over-condensing the giant serif; apply the tight `-0.05em` token to ~48–60px sans display and back off to ~-0.01em at 76px+. Body sits near 0. Font-features are on: stylistic sets `ss01`/`ss03`/`ss04`/`ss11` (Inter alternates) and `"liga" 0` in places; type is fluid (clamp). Body leading is generous (24px on 16px = 1.5).
- **Color:** Dark monochrome system. `bg #000` → near-black surfaces `#0b0e14` → text `#f0f0f0` → `muted #a1a4a5` → `subtle #6c6c6c`; borders are translucent off-white at ~8% alpha so dividers feel like light. Accent is violet `#9281f7` (with a hotter `#8300ff` for orb glows). The only other chroma is semantic: green `#44ffa4` (delivered/success/code-string), red `#ff6465` (bounced), amber/blue chips.
- **Spacing rhythm:** 8px base. Tight control clusters (4/6/8/12/16px gaps, paddingInline 14px on pills, 32px on cards) with large 96px vertical breaks between feature blocks. Whitespace (here, black space) is the primary separator; visible dividers are rare.
- **Layout system:** Centered, mostly single-column narrative — each feature is a centered text header above one large centered artifact. Breaks into multi-column for the quad feature grid (3-up: Intuitive analytics / Full visibility / Domain authentication), the testimonial marquee, and a 5-column footer. Viewport captured at 1440×900; mobile collapses to one column and, notably, renders the hero headline in the serif.
- **Motion / easing intent:** Restrained at the micro level, with two ambient "spectacle" exceptions (the 3D objects). Captured params: durations **150 / 200 / 300 / 500 / 600 / 1000 / 1500ms** (plus a `180000ms` ≈ 3-minute marquee loop), eased mostly by `cubic-bezier(0.4,0,0.2,1)` (Material standard) for hovers/states, with `cubic-bezier(0,0,0.2,1)` (decelerate-in) for reveals, `cubic-bezier(0.4,0,1,1)` (accelerate-out) for exits, and `cubic-bezier(0.36,0.66,0.6,1)` for the longer settles. **No stagger delays** were captured — group entrances move as one, not in sequence. The base micro-motion communicates responsiveness and "alive product"; the full choreography (load reveal, IO fade-ins, sticky editor, 3D objects, marquee) is detailed in **Interaction & motion** below.
- **Density:** Mixed — the embedded code editor and log/analytics UIs are genuinely dense, but the marketing chrome around them is sparse and high-contrast, so the page reads calm.
- **Hierarchy:** Dominant ordering device is **scale** (display vs body), reinforced by **typeface** (serif vs sans focal words) and value contrast (off-white on black).
- **Restraint:** No gradients on body text, no bright white cards, no drop-shadow-heavy floats, no multiple competing weights, no rainbow accent system. Color is rationed to one violet plus semantic green/red. The serif is used on only two or three headlines all page.
- **Grid / container:** Centered narrative column on a 1440px viewport; multi-column blocks captured at **2 / 3 / 5 / 6 columns** (`gridCols [2,3,6,5]`) — 2-up feature pairs, the 3-up testimonial/feature quad, a 5-up secondary row, and the **6-column footer** — all collapsing to **1–2 columns on mobile (390px)**. The re-probe now measures a **centered ~1280px content container** (nav span ≈104→1336px, ~104px side margins; the 1024/768px values are narrower inner artifacts) with a **~16px card gutter** (tight 16–32px band overall). H1 downscales 96px → 64px desktop→mobile; nav drops from 4 visible links to a hamburger.
- **Components (captured states):** **Button** — fully-pill or small-radius dark fills (primary = near-black "Get started", secondary = ghost/outline); hover is a subtle `background`/`border` lift on the `0.4,0,0.2,1` ease (no hover-state deltas were captured in the probe, so treat hover as light-touch). **Card** (feature / testimonial) — barely-lifted near-black surface (`#0b0e14`) or fully transparent with only a ~8% hairline border; elevation is hairline-over-shadow, not drop shadow; a `column-border-flash` keyframe briefly flashes a card's border on entry. **Nav** — text buttons with disclosure carets (8 disclosure triggers, 33 tab nodes for the mega-menus); the bar itself slides in via `header-slide-down-fade` and floats translucent over pinned content. **Input** — code-editor field with a blinking caret (`caret-blink` / `ProseMirror-cursor-blink`) and a focus selection pulse (`ai-selection-pulse`); standalone form inputs weren't on the captured pages. **Disabled** states: none captured (define your own — disabled was empty in the probe).
- **A11y (honest):** **focus-visible is present** (`focus_visible: true`) — but the focus indicator is **not a box-shadow ring** (all captured focus `box-shadow`s are transparent), so it's an `outline`/other treatment; verify it's actually visible on the black field. **`prefers-reduced-motion` is respected** (1 PRM rule; the 3D/marquee should freeze). **Image alt coverage is perfect — `img_alt_ratio: 1.0`** across 92 images. **Defect:** **73 of 107 interactive elements have small tap targets** (< ~44px) — the dense mega-nav and pill rows are below the comfortable touch minimum; enlarge hit areas on mobile. Color caveat carries from above: keep `subtle #6c6c6c` off fine print.

## Interaction & motion

Resend's motion is **mostly restrained + functional, with two ambient WebGL "spectacle" objects** that carry the brand mood. Evidence from the capture: **40 `@keyframes`**, **7 `IntersectionObserver`s over 66 targets**, 14 scroll listeners, **16 mousemove listeners**, **~551 `requestAnimationFrame` calls during one scroll pass** (the 3D scenes loop), 1 `<canvas>` + 5 `<video>` nodes, and **1 `prefers-reduced-motion` block — reduced motion is respected.** No GSAP/Lenis/Framer globals; it's hand-rolled CSS keyframes + IntersectionObserver + a WebGL/canvas loop. IO is tuned to threshold `0` (fire on first pixel) with a generous `rootMargin: 200px` (pre-warm before entry). Stack: `IntersectionObserver` · CSS `@keyframes` · WebGL/`<canvas>` + rAF. Watched across frames s00→s09: a load reveal at the top, per-section opacity fade-ins down the deliverability list, the code editor holding the viewport mid-scroll, the two 3D objects, and a testimonial marquee.

- **Load entrance reveal (no stagger)** — *Trigger:* load. *Mechanism:* the announcement pill + hero block flip `opacity` 0→1 and slide-up via `@keyframes hero-text-slide-up-fade` / `header-slide-down-fade`, first change at ~150ms; the group moves together (no per-item delay captured). *Reads as:* the page "arrives" composed rather than popping in. *Transfers to:* any hero/above-the-fold. *Safety:* **production-safe** (opacity+transform, one-shot, gated). → `scroll-reveal-in-view` (group).
- **In-view fade-rise reveal** — *Trigger:* in-view (IO, 66 targets, threshold 0). *Mechanism:* one class flip on intersect → `opacity` 0→1 (+ small rise), fired once; observed across nine deliverability cards ("Proactive blocklist tracking", "Faster time to inbox", "Build confidence with BIMI", "Managed dedicated IPs", "Dynamic suppression list", "IP and domain monitoring"…). *Reads as:* a tall page that settles in section by section. *Transfers to:* any long marketing/docs page. *Safety:* **production-safe** (GPU-cheap, once-only, reduced-motion off). → `scroll-reveal-in-view`.
- **Sticky-pinned product editor** — *Trigger:* scroll-progress. *Mechanism:* the code-editor / rendered-email artifact pins (`position: sticky`; capture shows `pin: 2`) and holds the viewport while the nav bar floats over and the next headline ("Reach humans, not…") scrolls up beneath it (frame s06). *Reads as:* scrollytelling — the product stays as fixed evidence while the argument advances. *Transfers to:* code/editor or dashboard feature deep-dives. *Safety:* **production-safe** (native sticky, no JS). → `sticky-pin-scrollytelling`.
- **Pointer-reactive 3D brand objects** — *Trigger:* load + hover/mousemove (16 mousemove listeners). *Mechanism:* a WebGL/`<canvas>` scene renders the hero cube (s00) and the camera-lens orb (s03) with a violet internal glow; it enters via `@keyframes webgl-scale-in-fade` / `hero-scale-in` and runs a continuous rAF loop (`rotate`, `spin`) that subtly tracks the pointer (~551 rAF/scroll pass). *Reads as:* a crafted, "lit-from-within" centerpiece that feels physical and alive. *Transfers to:* a single brand hero moment on a premium dark product. *Safety:* **spectacle-only** — it's the most expensive thing on the page (live WebGL + rAF + mousemove). Lazy-init on in-view, pause off-screen, ship a static poster under reduced-motion, and never put more than one per fold. (No standalone snippet — bespoke 3D; reuse the *principle*, gated + pausable.)
- **Shimmer / glow accents** — *Trigger:* load/continuous (gated). *Mechanism:* the announcement pill runs an animated gradient border and the AI copy uses a moving sheen (`@keyframes ai-shimmer-text`, `ai-selection-pulse`, `shine`, `disco`, `pulse`) — a slow looped background-position/gradient sweep. *Reads as:* "newest thing" / "AI is live" — one glowing affordance against flat dark UI. *Transfers to:* changelog/announcement entry points, AI-feature labels. *Safety:* **production-safe when gated** behind `prefers-reduced-motion`; keep it a cheap CSS gradient sweep, not a video, and cap to one or two on screen.
- **Testimonial marquee** — *Trigger:* load (continuous). *Mechanism:* the quote row auto-scrolls horizontally via `@keyframes scroll-x` on a ~180s loop (frame s09 social-proof band). *Reads as:* an endless wall of proof without a pager. *Transfers to:* logo walls, testimonial / changelog tickers. *Safety:* **production-safe** — pause on hover/focus and duplicate the track for a seamless loop; honor reduced-motion by freezing it. → `announcement-ticker-marquee`.

## Production-safety note

This is a real shipping product site; everything here is production-oriented.
- Dark monochrome + 1 violet accent: **production-safe**. A11y caveat — verify `subtle #6c6c6c` on `#000` (~4.6:1) and especially any small muted text meets 4.5:1; use `#a1a4a5`+ for fine print.
- Scale/typeface-driven hierarchy in light weights: **production-safe**, zero cost.
- Two display faces incl. a serif: **production-safe** but a **payload note** — subset the serif to display weights + latin only (it's used for a handful of words); don't ship a full serif family for two headlines.
- Code-block hero with framework tabs: **production-safe**; render server-side highlighted HTML (not a client editor lib) and lazy-init any "run/copy" JS so the LCP code block isn't JS-blocked.
- Embedded dark mini-UIs / large hero render: **production-safe** but a **perf watch** — ship responsive `srcset`/AVIF and lazy-load below the fold (page is ~12k px tall).
- Animated gradient-border badge + orb glows: **production-safe** when gated behind `prefers-reduced-motion`; keep the glow as a cheap CSS radial-gradient, not a video.
- Semantic tint + colored text on dark: **production-safe**; cheap and adapts to surface depth.
